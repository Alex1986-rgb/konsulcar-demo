# КонсулКар — демонстрационная версия сайта

Статическая демо-сборка сайта единого центра автоуслуг «КонсулКар» для согласования с заказчиком.

**Это демонстрация, не рабочий сайт.**

- Наполнение и часть фотографий — примеры. Телефон, адрес, реквизиты и цены появятся после согласования.
- Формы на демо-версии не отправляются: приём заявок работает на PHP (почта + amoCRM), а GitHub Pages статический.
- Демо закрыто от поисковых систем (`noindex`, `robots.txt`), чтобы не конкурировать с будущим рабочим сайтом.

Исходники сайта и генераторы страниц живут отдельно; здесь только собранная статика.
